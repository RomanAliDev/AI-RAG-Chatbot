# AI RAG Chatbot

An AI-powered chatbot that uses Retrieval-Augmented Generation (RAG) to answer questions using uploaded documents.

## Features

- User registration and login
- AI-powered chat using Google Gemini
- Document upload and question answering
- Retrieval-Augmented Generation (RAG)
- Conversation history
- User-specific conversations and documents
- PostgreSQL database with pgvector for vector search

## Tech Stack

Frontend: React, Vite

Backend: FastAPI, Python

AI: LangChain, Google Gemini

Database: PostgreSQL, pgvector

Authentication: JWT

## Status

Developed as a portfolio project to explore AI, RAG, and full-stack application development.
